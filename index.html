Projeto 01 • Segurança da Informação

🔐 Cofre Digital Interativo em Python

O que o projeto faz?

Muitas pessoas com pouca familiaridade digital — especialmente idosos — anotam senhas e contatos de emergência em blocos de notas comuns. Nosso programa em Python usa input() e uma chave secreta para embaralhar (criptografar) o texto e restaurá-lo somente com a mesma chave.

📄 Ver Código-Fonte em Python 
import base64

def criptografar(texto, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    cifrado = bytes([(b + deslocamento) % 256 for b in texto.encode("utf-8")])
    return base64.b64encode(cifrado).decode("utf-8")

def descriptografar(codigo, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    dados = base64.b64decode(codigo.encode("utf-8"))
    return bytes([(b - deslocamento) % 256 for b in dados]).decode("utf-8")

modo = input("1 - Criptografar | 2 - Descriptografar: ")
msg = input("Mensagem ou código: ")
chave = input("Chave secreta: ")
print(criptografar(msg, chave) if modo == "1" else descriptografar(msg, chave))

Projeto 03 • Ciência de Dados & Saúde

🥗 Modelo Computacional Nutricional em Python

Como ajuda na saúde?

Calcula automaticamente energia (kcal), carboidratos (g), fibras (g) e sódio (mg) conforme a porção em gramas, emitindo alertas preventivos para hipertensos e diabéticos.

📄 Ver Código-Fonte em Python 
TABELA = {
    "arroz":    {"kcal": 130, "carb": 28.0, "fibras": 1.6, "sodio": 1},
    "feijao":   {"kcal": 76,  "carb": 13.6, "fibras": 8.5, "sodio": 2},
    "frango":   {"kcal": 159, "carb": 0.0,  "fibras": 0.0, "sodio": 50},
    "embutido": {"kcal": 290, "carb": 2.5,  "fibras": 0.0, "sodio": 980}
}
alimento = input("Alimento: ").lower().strip()
gramas = float(input("Gramas: "))
fator = gramas / 100.0
dados = TABELA[alimento]
print(f"Calorias: {dados['kcal']*fator:.1f} kcal | Sódio: {dados['sodio']*fator:.0f} mg")

🧮 Simulador Nutricional

195.0 kcal | Carb: 42.0 g | Fibras: 2.4 g | Sódio: 2 mg

✅ Valores equilibrados para a porção.

Como LEDs e Código Morse Ajudam Pessoas com Deficiências?

Combinar sinais visuais (LEDs e Displays) com sinais auditivos (Buzzer em Código Morse) derruba barreiras de comunicação em escolas, hospitais e espaços públicos, garantindo autonomia para diferentes perfis de usuários:

👂 Deficiência Auditiva (Surdez)

Alarmes puramente sonoros não são percebidos por pessoas surdas. A Matriz de LEDs e as piscadas luminosas do Código Morse convertem alertas e pedidos de socorro em sinais visuais de alto brilho.

👁️ Deficiência Visual (Cegueira / Baixa Visão)

Telas e placas escritas excluem pessoas cegas. O Buzzer (campainha sonora) emite bipes curtos e longos em Código Morse, permitindo identificar alertas e mensagens pelo ouvido sem depender da visão.

🦾 Deficiência Motora Severa / Não Verbais

Pessoas com tetraplegia, ELA ou afasia (sem fala) podem acionar um único botão adaptado (toque leve, sopro ou piscar) para transmitir SOS, AJUDA, SIM ou NÃO via LED e Buzzer.

🧠 Deficiência Intelectual / Baixo Letramento

Ícones simples na Matriz de LEDs (como rosto feliz/triste, cruz de socorro ou seta de saída) comunicam necessidades imediatas sem exigir leitura de textos longos.

Recurso Visual • Matriz de LEDs

🔲 Matriz de LEDs para Comunicação Rápida

Como funciona?

Uma matriz de LEDs organiza diodos luminosos em linhas e colunas. O microcontrolador acende coordenadas específicas (multiplexação) para desenhar símbolos universais, emoções ou setas de direção visíveis mesmo em ambientes barulhentos.

✅ Vantagens: Alto brilho, leitura visual instantânea e independência de alfabetização.
⚠️ Limitações: Baixa resolução para frases longas; perda de contraste sob sol forte; exige apoio sonoro para pessoas cegas.

Recurso Visual + Auditivo • Código Morse

⚡ Código Morse: Luz (LED) e Som (Buzzer)

Comunicação Dupla: Visual e Auditiva

O Código Morse codifica letras em pulsos curtos (pontos •) e pulsos longos (traços —). No protótipo com Arduino, cada pulso aciona simultaneamente:

  • LED (Sinal Visual): Pisca curto ou longo para pessoas surdas ou ambientes barulhentos.
  • Buzzer (Sinal Auditivo): Emite bipe curto (200ms) ou longo (600ms) para pessoas cegas ou chamadas à distância.
Exemplo: AJUDA = • — (A)   • — — — (J)   • • — (U)   — • • (D)   • — (A)
