Atividade 1 - Seguranca Digital com Criptografia

Cofre Digital Interativo em Python

O Problema e o Publico Beneficiado

Familiares idosos ou com pouca experiencia digital costumam anotar senhas e contatos de emergencia em blocos de notas comuns, ficando expostos a golpes na internet.

Como funciona o algoritmo?

  • Entrada de dados (input()): Recebe a mensagem confidencial e uma chave secreta.
  • Criptografia reversivel: Desloca cada caractere conforme a chave e gera um codigo embaralhado seguro.
  • Descriptografia: Ao inserir o codigo embaralhado e a mesma chave, o texto original volta ao normal.
Ver Codigo-Fonte em Python (Cofre Digital) 
import base64

def criptografar(texto, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    cifrado = bytes([(b + deslocamento) % 256 for b in texto.encode("utf-8")])
    return base64.b64encode(cifrado).decode("utf-8")

def descriptografar(codigo_b64, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    cifrado = base64.b64decode(codigo_b64.encode("utf-8"))
    return bytes([(b - deslocamento) % 256 for b in cifrado]).decode("utf-8")

op = input("1 - Criptografar | 2 - Descriptografar: ")
msg = input("Digite a mensagem ou codigo: ")
chave = input("Digite a chave secreta: ")
print(criptografar(msg, chave) if op == "1" else descriptografar(msg, chave))

Atividade 3 - Modelos Computacionais Avancados em Python

Analise Nutricional Automatizada e Acessivel

Democratizacao dos Dados de Saude

Idosos, pessoas em reabilitacao alimentar ou com diabetes e hipertensao precisam monitorar calorias, carboidratos, fibras e sodio. Nosso modelo em Python automatiza esse calculo proporcionalmente.

Para garantir responsabilidade etica, o sistema exibe todas as unidades (kcal, g, mg) e gera alertas preventivos quando o sodio ou carboidrato passa dos limites recomendados.

Ver Codigo-Fonte em Python (Modelo Nutricional) 
ALIMENTOS = {
    "arroz":   {"kcal": 130, "carb": 28.0, "fibras": 1.6, "sodio": 1},
    "feijao":  {"kcal": 76,  "carb": 13.6, "fibras": 8.5, "sodio": 2},
    "frango":  {"kcal": 159, "carb": 0.0,  "fibras": 0.0, "sodio": 50},
    "salada":  {"kcal": 20,  "carb": 3.5,  "fibras": 2.4, "sodio": 12},
    "embutido":{"kcal": 290, "carb": 2.5,  "fibras": 0.0, "sodio": 980}
}
alim = input("Alimento: ").lower().strip()
gramas = float(input("Quantidade (g): "))
if alim in ALIMENTOS:
    f = gramas / 100.0
    d = ALIMENTOS[alim]
    print(f"Energia: {d['kcal']*f:.1f} kcal | Sodio: {d['sodio']*f:.0f} mg")

Parte B - Recurso 1

Matriz de LEDs

Como funciona?

Placa formada por diodos organizados em linhas e colunas (grade 8x8). O microcontrolador acende coordenadas especificas rapidamente (multiplexacao), formando desenhos, setas ou simbolos.

  • Emocoes e Necessidades: Rosto alegre, rosto triste, atencao (!) ou ajuda (+).
  • Direcao e Uso Concreto: Setas para saida acessivel ou alerta visual na mesa de aluno nao verbal em sala barulhenta.
Vantagens: Alto brilho, resposta imediata e leitura visual por icones simples.
Limitacoes: Baixa resolucao para frases longas; perda de visibilidade sob sol forte ou longa distancia; exige conhecer o simbolo.

Previa Interativa: Matriz de LEDs (5x5)

Parte C - Recurso 2

Codigo Morse

Como funciona?

Representa letras e numeros por sinais curtos (pontos) e sinais longos (tracos). No circuito, o botao envia o pulso, o LED pisca e o buzzer emite bipes sonoros.

Mensagem: AJUDA = .- (A) .--- (J) ..- (U) -.. (D) .- (A)

Situacao concreta: Pessoas com tetraplegia ou ELA acionam um unico botao adaptado para pedir socorro ou responder SIM/NAO.

Vantagens: Exige apenas um comando simples e combina luz (LED) e som (buzzer).
Limitacoes: Exige decodificacao; som nao atende surdos; luz nao atende cegos; requer adaptacao fisica do botao.

Parte D - Recurso 3

Display (Visor LCD / OLED)

Como funciona e limites de acessibilidade

Tela eletronica que exibe letras, numeros e frases curtas para orientar ou alertar em hospitais e escolas. Porem, o texto sozinho nao garante acessibilidade universal: pessoas cegas, com baixa visao, nao alfabetizadas ou estrangeiras ainda enfrentam barreiras.

Vantagens: Mensagem escrita direta, sem necessidade de decodificar simbolos.
Limitacoes: Tela pequena (2x16), contraste limitado, idioma e inacessivel para cegos sem audio.

Previa Interativa: Display LCD 16x2
