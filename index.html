Atividade 1 • Segurança Digital com Criptografia

🔐 Cofre Digital Interativo em Python

O Problema e o Público Beneficiado

Muitas pessoas — especialmente familiares idosos ou com pouca familiaridade digital — anotam senhas, dados bancários e contatos de emergência em blocos de notas comuns, ficando vulneráveis a vazamentos e golpes na internet.

Como funciona o algoritmo?

  • Entrada de dados (input()): O usuário informa a mensagem confidencial e define uma chave secreta.
  • Criptografia reversível: Cada caractere é deslocado conforme a chave secreta e convertido em código seguro.
  • Descriptografia: Ao colar o código embaralhado e digitar exatamente a mesma chave, o sistema restaura o texto original.

Validação e Experiência do Usuário

Testamos o fluxo em equipe e com colegas de outro grupo: criptografamos um contato de emergência, copiamos o código gerado e o restauramos com a mesma chave, ajustando as mensagens do terminal para ficarem claras.

📄 Ver Código-Fonte em Python (Cofre Digital) 
import base64

def criptografar(texto, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    bytes_texto = texto.encode("utf-8")
    cifrado = bytes([(b + deslocamento) % 256 for b in bytes_texto])
    return base64.b64encode(cifrado).decode("utf-8")

def descriptografar(codigo_b64, chave):
    deslocamento = sum(ord(c) for c in chave) % 256
    cifrado = base64.b64decode(codigo_b64.encode("utf-8"))
    original = bytes([(b - deslocamento) % 256 for b in cifrado])
    return original.decode("utf-8")

opcao = input("1 - Criptografar | 2 - Descriptografar: ")
msg = input("Digite a mensagem ou código: ")
chave = input("Digite a chave secreta: ")

if opcao == "1":
    print("Código protegido:", criptografar(msg, chave))
elif opcao == "2":
    print("Mensagem restaurada:", descriptografar(msg, chave))

Atividade 3 • Modelos Computacionais Avançados em Python

🥗 Análise Nutricional Automatizada e Acessível

Como a Programação Democratiza a Saúde?

Idosos, pessoas em reabilitação alimentar ou com condições como diabetes e hipertensão precisam controlar diariamente calorias, carboidratos, fibras e sódio. Nosso modelo em Python aplica cálculo proporcional sobre tabelas nutricionais para entregar respostas imediatas.

Responsabilidade Ética e Clareza

Para evitar interpretações erradas, o sistema exibe as unidades de medida por extenso (kcal, g, mg), emite alertas preventivos quando o sódio ou carboidrato ultrapassa limites de atenção e informa que não substitui acompanhamento médico.

📄 Ver Código-Fonte em Python (Modelo Nutricional) 
ALIMENTOS = {
    "arroz":   {"kcal": 130, "carb": 28.0, "fibras": 1.6, "sodio": 1},
    "feijao":  {"kcal": 76,  "carb": 13.6, "fibras": 8.5, "sodio": 2},
    "frango":  {"kcal": 159, "carb": 0.0,  "fibras": 0.0, "sodio": 50},
    "salada":  {"kcal": 20,  "carb": 3.5,  "fibras": 2.4, "sodio": 12},
    "embutido":{"kcal": 290, "carb": 2.5,  "fibras": 0.0, "sodio": 980}
}

alimento = input("Alimento: ").lower().strip()
gramas = float(input("Quantidade em gramas: "))

if alimento in ALIMENTOS:
    fator = gramas / 100.0
    dados = ALIMENTOS[alimento]
    sodio_total = dados["sodio"] * fator
    print(f"Calorias: {dados['kcal']*fator:.1f} kcal | Fibras: {dados['fibras']*fator:.1f} g | Sódio: {sodio_total:.0f} mg")
    if sodio_total > 400:
        print("ALERTA PREVENTIVO: Alto teor de sódio (atenção para hipertensos)!")

Parte B • Recurso 1

🔲 Matriz de LEDs

Como funciona?

Uma matriz de LEDs é uma placa formada por diodos emissores de luz organizados em linhas e colunas (como uma grade 8x8). Ao enviar corrente elétrica para coordenadas específicas (multiplexação), o microcontrolador acende apenas os pontos desejados, formando desenhos, setas ou símbolos luminosos.

Símbolos que comunicam

  • Emoções: Rosto sorridente (bem-estar/alegria) ou rosto triste (desconforto/dor).
  • Necessidades e Avisos: Exclamação ! (atenção), cruz ou SOS (ajuda urgente).
  • Direção: Setas apontando para saída de emergência, rampa acessível ou sala de atendimento.

Situação concreta de uso

Em uma escola ou hospital barulhento, uma matriz de LEDs na mesa de um aluno não verbal ou na parede do corredor mostra um ícone de “Ajuda” ou uma seta direcional, facilitando o entendimento imediato mesmo para pessoas surdas ou não alfabetizadas.

✅ Vantagens: Alta luminosidade, resposta instantânea e comunicação visual por ícones simples.
⚠️ Limitações: Baixa resolução para frases longas; perda de visibilidade sob sol forte ou grandes distâncias; exige que o observador entenda o símbolo exibido.
